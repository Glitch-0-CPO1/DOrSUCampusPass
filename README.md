# DOrSU Digital Campus Pass

A React Native (Expo) mobile app built for ITMSD1 — Lab Activity 03. It simulates a digital student ID / campus gate pass, featuring a reusable Student Card component, a live gate-scan counter, a pass-suspension toggle, and a peer props demo showing the same component reused with different data.

## Features
- Student ID card built with typed props (StudentProfile)
- Gate scan counter using useState with functional updates
- Pass suspension toggle (StatusBadge: ACTIVE/SUSPENDED)
- Peer Props Demo — renders a second student card to prove component reusability

## Getting Started
```bash
npm install
npx expo start
```
Scan the QR code with the Expo Go app on your phone to run it.
